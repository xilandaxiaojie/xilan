# Xilan Studio

西兰博客的桌面管理工具。登录 GitHub、写文章、看实时预览、一键发布，不用碰命令行。

---

## 快速开始

### 方式一：运行打包好的程序

进入 `release/Xilan Studio-win32-x64/`，双击 **Xilan Studio.exe**。

如果双击没反应，改用 **启动.bat**——它会清掉干扰的环境变量，并在出错时把退出码显示出来。

> 启动不了？见 [启动排查.md](启动排查.md)。

### 方式二：从源码运行

```bash
cd studio
npm install
npm run dev
```

需要本机已安装 **Git**，并且 `git` 命令在 PATH 中。

## 第一次使用

### 1. 准备 GitHub Token

打开软件后点「GitHub 设置」链接，或直接访问：

<https://github.com/settings/tokens/new?scopes=repo&description=Xilan%20Studio>

- **Note** 随便填，比如 `Xilan Studio`
- **Expiration** 建议选 90 天或 No expiration
- **Scopes** 只需要勾选 `repo`
- 点最下面 **Generate token**
- 复制生成的 `ghp_xxx…`（**这个只显示一次**）

粘贴进软件，点「登录」。

> Token 保存在本机的用户数据目录，不会上传到任何地方。

### 2. 选择仓库

登录后有两种方式：

**克隆到本地** —— 从下拉框选 `你的用户名/xilan`，点「克隆」，第一次会让你选存到哪个文件夹。

**打开已有目录** —— 如果你已经 `git clone` 过了，直接选那个文件夹。

软件会检查目录里有没有 `.git`、`posts/` 或 `notes/`，不符合会提示。

### 左侧：文章列表

- **文章 / 手记** 标签页切换
- **搜索框** —— 搜标题、标签、正文摘要
- **标签筛选** —— 点标签只看含该标签的条目
- **置顶** 的文章显示 📌
- 有未提交改动的条目右侧有小黄点

### 中间：编辑区

上半部分是 frontmatter 表单：

| 字段 | 说明 |
|---|---|
| 标题 | 文章必填，手记没有这个字段 |
| 日期 | 决定排序 |
| 摘要 | 显示在卡片和 SEO |
| 分类 | 只能一个，可从已有分类选 |
| 标签 | 输入后回车添加，下面会列出常用标签点选 |
| 封面 | 留空则按仓库规则自动随机 |
| 置顶 | 文章列表和首页排最前 |
| 草稿 | 勾选后不显示在站点上 |

下半部分是编辑器，三种视图：

- **分栏** —— 左边写，右边实时预览
- **编辑** —— 全屏写作
- **预览** —— 全屏看效果

右上角显示保存状态，**编辑后 1.2 秒会自动保存到本地文件**，也可以 `Ctrl+S` 立即保存。

### 右侧：变更栏

列出所有未提交的文件改动：

- `A` 新增 / `M` 修改 / `D` 删除
- 点任意一行可以看那个文件的具体 diff

### 发布

点右上角「发布」→ 弹出确认框：

1. 上方列出所有要提交的文件
2. 中间是完整的 diff（绿=新增，红=删除）
3. 下方填提交说明（会自动建议，比如「新增文章：xxx」）
4. 点「确认提交并推送」

推送成功后 GitHub Actions 会自动构建，大约 1 分钟线上生效。

## 图片怎么放

**拖拽** —— 直接把图片文件拖进编辑区，自动上传并插入 Markdown。

**粘贴** —— 截图后 `Ctrl+V`，同样自动上传。

**点「插入图片」** —— 选择本地文件。

图片会存到**文章自己的文件夹**：

```
posts/
└── 我的文章/
    └── images/
        ├── 截图.png
        └── 配图.jpg
```

正文里插入的路径是：

```markdown
![描述](posts/我的文章/images/截图.png)
```

### 图片面板

打开有图片的文章，编辑器下方会出现图片条：

- **点缩略图** —— 再次把这张图插入正文
- **悬停点 ×** —— 删除这张图

### 为什么要按文章分目录

- 文章删掉时图片一起删，不留垃圾
- 文章改名时图片目录跟着走，路径自动不错乱
- 几十篇文章的图片混在一个目录里很难找

## 与博客仓库的约定

软件严格按你博客的目录结构工作：

```
仓库根/
├── posts/            文章（.md）
│   └── 文章名/
│       └── images/   该文章的图片
├── notes/            手记（.md）
├── covers/           封面库，未指定时随机取
└── images/           通用图片
```

**frontmatter 格式**与你手写时完全一致，软件不会加奇怪的东西：

```yaml
---
title: 我的文章
description: 一句话摘要
date: 2025-11-20
tags:
  - 随笔
  - 建站
category: 日常
pinned: true
---
```

所以你可以随时回到 Obsidian 或任何编辑器继续写，两者不冲突。

## 常见问题

**登录失败？**
检查 Token 是否勾选了 `repo` 权限，以及有没有复制完整（`ghp_` 开头）。

**提示「不是博客仓库」？**
选中的目录需要包含 `.git` 文件夹，以及 `posts/` 或 `notes/` 之一。

**克隆失败？**
确认本机装了 Git（命令行运行 `git --version` 有输出）。

**发布失败？**
常见原因：
- 没有网络
- Token 过期（重新生成）
- 远端有新提交导致冲突（先点软件里的刷新，或命令行 `git pull`）

**想换仓库？**
目前需要重新登录或重新选目录。配置文件在：
`C:\Users\<你>\AppData\Roaming\Xilan Studio\config.json`

**浏览器预览模式**
开发时可以用 `node scripts/preview-server.mjs 4322`，然后用浏览器打开 `http://localhost:4322`。
这个模式下不支持 GitHub 登录和克隆，只用来调界面和本地文件。

## 开发

```bash
npm run dev          # 启动 Electron
npm test             # 跑全部测试（221 项）
npm run preview      # 浏览器预览模式，看 http://localhost:4322
npm run pack         # 打包到 release/
```

单独跑某一项测试：

```bash
node scripts/test-core.mjs      # 核心逻辑 39 项
node scripts/test-e2e.mjs       # 完整写作流程 48 项
node scripts/test-ipc.mjs       # IPC 接口 48 项
node scripts/test-ui.mjs        # 界面一致性 35 项
node scripts/test-browser.mjs   # 真实浏览器交互 19 项（需先 npm run preview）
node scripts/verify-package.mjs # 打包产物结构 32 项
```

### 代码结构

```
studio/
├── electron/
│   ├── main.cjs        主进程：窗口 + IPC 处理器
│   └── preload.cjs     安全桥接，暴露白名单 API
├── src/
│   ├── core/           与界面无关的业务逻辑
│   │   ├── frontmatter.js  解析/生成 frontmatter
│   │   ├── repo.js         文章与图片读写
│   │   ├── git.js          git 操作
│   │   ├── markdown.js     Markdown 渲染
│   │   └── github.js       GitHub API
│   └── ui/             界面
│       ├── index.html
│       ├── styles.css
│       └── app.js
└── scripts/            测试与开发工具
```

核心逻辑与界面完全分离，想做成网页版只需换掉 `src/core/repo.js` 里的文件读写部分。
