# 启动失败排查

这里收集几种自己动手定位问题的方法，从最简单的开始。

---

## 第 1 步：确认是不是环境变量的问题

Electron 有一个环境变量 `ELECTRON_RUN_AS_NODE`，一旦被设成 `1`，
程序会**以纯 Node 模式启动，完全不创建窗口，然后立刻退出**——
表现和「双击没反应」一模一样。

**用 PowerShell 检查：**

```powershell
[Environment]::GetEnvironmentVariable("ELECTRON_RUN_AS_NODE", "User")
[Environment]::GetEnvironmentVariable("ELECTRON_RUN_AS_NODE", "Machine")
```

如果任何一个输出了 `1`，就是它。

**临时清除（当前窗口有效）：**

```powershell
$env:ELECTRON_RUN_AS_NODE = $null
& "D:\DSH\博客\studio\release\Xilan Studio\Xilan Studio.exe"
```

**永久清除：**

```powershell
[Environment]::SetEnvironmentVariable("ELECTRON_RUN_AS_NODE", $null, "User")
```

然后关掉所有终端重新打开，再双击一次。

> 这个变量常被一些开发工具（VS Code 的某些插件、nvm、部分 Node 管理器）设置。

---

## 第 2 步：用命令行启动，把错误显示出来

双击时看不到任何信息，改成命令行就能看到报错：

```powershell
cd "D:\DSH\博客\studio\release\Xilan Studio"
.\"Xilan Studio.exe" --enable-logging
```

如果程序正常，会打开窗口；
如果有错，终端里会出现文字。把那些文字发给我。

---

## 第 3 步：确认 exe 没被系统拦截

从网络下载或从别的盘复制过来的 exe，Windows 可能加了「阻止」标记。

**方法一（界面）：** 右键 `Xilan Studio.exe` → 属性 → 如果底部有「解除锁定」的勾选框，勾上 → 确定。

**方法二（命令行）：**

```powershell
Unblock-File "D:\DSH\博客\studio\release\Xilan Studio\Xilan Studio.exe"
```

---

## 第 4 步：确认运行时文件完整

exe 单独一个文件跑不起来，必须跟整个文件夹在一起。检查这些文件是否存在：

```powershell
cd "D:\DSH\博客\studio\release\Xilan Studio"
@("icudtl.dat","libEGL.dll","libGLESv2.dll","ffmpeg.dll",
  "v8_context_snapshot.bin","resources.pak","resources\app\electron\main.cjs") |
  ForEach-Object { "{0,-40} {1}" -f $_, (Test-Path $_) }
```

全部应该是 `True`。如果 `resources\app` 缺失，说明打包或复制过程出了问题，重新打包一次：

```powershell
cd "D:\DSH\博客\studio"
npm run dist
```

---

## 第 5 步：换个方式运行（开发模式）

如果打包版怎么都起不来，直接用源码跑，这样能拿到最完整的报错：

```powershell
cd "D:\DSH\博客\studio"
npm install
npm run dev
```

控制台会立即显示错误堆栈。

---

## 第 6 步：显卡/远程桌面相关

如果是在**远程桌面**、**虚拟机**或者**极老/极新的显卡驱动**上：

```powershell
cd "D:\DSH\博客\studio\release\Xilan Studio"
.\"Xilan Studio.exe" --disable-gpu
```

还不行就再加上软件渲染：

```powershell
.\"Xilan Studio.exe" --disable-gpu --disable-software-rasterizer
```

---

## 如果以上都不行

把下面这些信息发给我，我据此定位：

1. 第 2 步命令行启动时的完整输出
2. 你的 Windows 版本：`winver` 的输出，或 `[Environment]::OSVersion`
3. 第 1 步两个环境变量的输出结果

直接在 `posts/` 里新建 `.md` 文件、`git push`，博客照样发布，工具只是省事而已。
