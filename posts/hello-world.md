欢迎来到我的小站。

这是一个用 **Astro** 搭建的静态博客，主色是初音绿，界面走的是干净、轻盈的路子。

## 为什么做这个站

大概是因为，总有一些东西想要留下来。

> 所谓浪漫，就是没有后来。
>
> 但如果能把它写下来，或许就不一样了。

我把这里当成一个小小的抽屉：动画感想、代码笔记、随手拍的照片、半夜想出来的句子——都可以往里放。

## 技术上是怎么实现的

整个站点是纯静态的。没有数据库，没有后端服务，甚至连服务器都不需要。

```
posts/            # 长文章
notes/            # 短手记
images/           # 文章里用到的图片
covers/           # 封面图，没指定时自动从这里挑
src/
├── components/   # 界面组件
├── layouts/      # 页面骨架
└── styles/       # 样式
```

写文章就是新建一个 Markdown 文件：

```markdown
---
title: 文章标题
date: 2025-08-12
tags: [标签一, 标签二]
---

正文内容……
```

然后 `git push`，GitHub Actions 会自动构建并部署。
