# 启动失败排查

## 已做的重要修复：升级到 Electron 44

**如果你的系统是 Windows 11 较新的版本（比如 Build 26300 这种 Insider 预览版），
旧版 Electron 33 会在启动阶段直接崩溃，表现就是双击完全没反应、没有任何日志。**

现在已经升级到 **Electron 44.9.0**（Chromium 版本新了十几个大版本），
重新打包后双击 `Xilan Studio.exe` 应该就能起来了。

如果还是不行，继续往下看。

---

## 确认你拿的是新版

```powershell
cd "D:\DSH\博客\studio\release\Xilan Studio-win32-x64"
Get-Content version
```

应该输出 `44.9.0`。如果输出 `33.4.11`，说明还是旧包，需要重新打包：

```powershell
cd "D:\DSH\博客\studio"
npm run pack
```

## 桌面版还打不开怎么办

### 第 1 步：用 诊断.bat

双击同目录的 `诊断.bat`，它会把退出码和完整日志显示出来。

### 第 2 步：检查安全软件

360、火绒、Windows Defender 的「受控文件夹访问」会静默杀掉未签名的程序。

Windows 安全中心 → 病毒和威胁防护 → 勒索软件防护 → 管理勒索软件防护 → 关闭
（或把 `release\Xilan Studio-win32-x64` 加入白名单）

在「保护历史记录」里也能看到有没有拦截记录。

### 第 3 步：解除文件锁定

```powershell
Unblock-File "D:\DSH\博客\studio\release\Xilan Studio-win32-x64\Xilan Studio.exe"
```

### 第 4 步：显卡相关参数

```powershell
cd "D:\DSH\博客\studio\release\Xilan Studio-win32-x64"
.\"Xilan Studio.exe" --disable-gpu
```

还不行加上 `--disable-gpu --no-sandbox`。
